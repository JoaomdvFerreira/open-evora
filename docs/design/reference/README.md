# Approved rendered design references

`reference/` contains human-approved rendered design artefacts. They are used for implementation and rendered comparison.

These artefacts do not define research semantics, React APIs, CSS architecture, or token names. Approval must be explicit before an artefact enters this directory.

Treat an approved artefact as immutable evidence. A materially revised design requires a new approved artefact rather than a silent rewrite of design history.
